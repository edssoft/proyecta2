# Proyecta2

Software gratuito de proyección a doble pantalla para iglesias, instituciones y eventos.

Panel de control limpio para el operador y pantalla de proyección sin cursor ni interfaz: videos, imágenes, Biblia, cámaras, YouTube y fondos institucionales, todo desde un solo lugar.

## Descargas

Descargá la última versión desde la sección **Releases** o desde la web oficial: https://edssoft.com.ar

- **Liviano**: videos, imágenes, cámaras y YouTube. Ideal para colegios, empresas y eventos.
- **Estándar**: versión general del programa.
- **Adventista**: incluye Biblias Reina Valera 1909 y 1865 y fondos institucionales.

Requisitos: Windows 10 u 11 y una segunda pantalla (TV o proyector) configurada en modo Ampliar.

Nota: al ejecutar el instalador, Windows puede mostrar el aviso "Windows protegió tu PC". Hacé clic en "Más información" y luego en "Ejecutar de todas formas".
